# Course Templates (Course v4.2)

Editable templates for the artifacts that Course.md section 14 lists and the module packages do not already supply.

| Template | File | Used from | Owner |
| --- | --- | --- | --- |
| Role Decision Record | [Role-Decision-Record.md](Role-Decision-Record.md) | M2 (Builder), M3 (Reviewer), M6 (Observer) | learner |
| Value Checkpoint entry | [Value-Checkpoint.md](Value-Checkpoint.md) | every module from M1 | learner |
| Learning Record entry | [Learning-Record.md](Learning-Record.md) | every module from M1 | Tutor (the only file it may write) |
| Facilitator Blocker Attestation | [Facilitator-Blocker-Attestation.md](Facilitator-Blocker-Attestation.md) | any module, only when direct blocker evidence cannot be produced | facilitator |

Rules that apply to all four:

- Separate observed evidence from assumptions. Mark every unknown `unknown`.
- Label each figure `estimate` or `measured`.
- Do not fabricate a run, a measurement, or a source. A blank field is better than an invented one.
- The examples are fictional and illustrative. They are not results from any learner or pilot.
