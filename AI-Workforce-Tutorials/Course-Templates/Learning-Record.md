# Learning Record

The Tutor writes this file at `learning/learning-record.md`. It is the only file the Tutor may write. See Course.md section 3.6.

What this record is: evidence of what the learner demonstrated about concepts.
What it is not: evidence that any run happened. Operational evidence lives in `runs/` and `outputs/`. The learning record is never an input to a run and never part of a Reviewer's evidence packet.

Who may read it: [facilitator decides before the cohort starts and tells the learners: learner only / learner and facilitator]

Rules for the Tutor:

- Record what the learner said or did, in their own words. Do not record a judgment about the person.
- A misconception is recorded for this learner only, as `tier-3d` (from the diagnostic) or `tier-3v` (observed in the session). Never copy it into a shared misconception map.
- Name a gap rather than crediting participation.
- Write nothing the learner has not seen. Show the entry after writing it.
