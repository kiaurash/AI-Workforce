```text

├── README.md
├── workspace-rules.md

│   └── sample-meeting.md
```

## Required output

The only expected created file is:

```text
outputs/commitments.md
```

Use the instruction in the [M0.5 Learner Workbook](../learner/M0.5-Workbook.md). Do not modify the source transcript or take external actions.

## Success check

The learner—not the agent—opens the source and output files, checks that the source remains unchanged, and spot-checks every listed commitment against the transcript.
