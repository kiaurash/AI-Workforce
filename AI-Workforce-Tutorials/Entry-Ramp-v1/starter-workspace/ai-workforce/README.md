# Entry Ramp v1 Capstone Workspace

This is the single learner workspace for M0, M0.5, and M1. Open the `ai-workforce/` folder in Hermes Desktop.

- **M0:** save discovery and safety artifacts here.
- **M0.5 Gate A:** read `inputs/sample-meeting.md` and create only `outputs/commitments.md`.
- **M0.5 Gate B:** use this same workspace when the Conductor creates its blocked run manifest and activation record.
- **M1:** replace the course sample with the learner-authorized `inputs/representative-input.md` and create a draft/proposal only.

Do not create a second workspace for M1. Read `workspace-rules.md` before running Gate A.
