# Risk / Approval Matrix

Hard gate: every row below must have a declared approval owner AND a declared evidence label before any roster or scaffold is emitted. A blank cell blocks emission exactly like an undefined owner — "not applicable" is itself a decision that must be stated explicitly, never left empty, and never copied from the illustrative examples below without doing the analysis.

**This is a template. The content in every cell under "Example In This Workflow," "Approval Owner," and "Evidence Label" is illustrative only — replace it per engagement; do not retain it as a default.** Treat an unreplaced placeholder exactly like a blank cell: it blocks emission.
